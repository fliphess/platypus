Binary secrets

Platypus shows a secret that holds binary data by its metadata only: no reveal, no editing. The reason is simple: values in platypus are text (UTF-8). Arbitrary bytes can't be shown safely in a page, saved from a form, or compared without corrupting them.

If a team needs the value in platypus, store it as text instead. Base64 is the usual way: put the encoded bytes in an ordinary secret, and decode them where they are used. That keeps the value revealable, editable and auditable like every other secret.

Reading a binary value yourself, with the AWS CLI:

aws secretsmanager get-secret-value --secret-id NAME --query SecretBinary --output text | base64 --decode > new-file

Writing one back (for example after rotating it):

aws secretsmanager put-secret-value --secret-id NAME --secret-binary fileb://new-file

A binary secret can be rotated and deleted the same way: `aws secretsmanager put-secret-value` and `aws secretsmanager delete-secret`. Platypus never deletes anything.
