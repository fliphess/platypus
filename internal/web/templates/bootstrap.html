1. Bootstrap token

Platypus wrote a one-time token to the SSM parameter {{.TokenParam}} in this AWS account. Copy it from the AWS console or CLI:

aws ssm get-parameter --with-decryption --name {{.TokenParam}} --query Parameter.Value --output text

Whoever enters it becomes the first admin, so only people with access to SSM can do this.
